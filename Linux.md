# What distro should i use?

whoa whoa, hang on, what even is a distro?

Well, Linux has these things called distros, which are basically versions of Linux.

For example, im assuming, if you are reading this, you are probably a beginner to linux, so you should probably start with Fedora linux. Which is probably
easier to download then windows.

Linux can pretty much run on a toaster, so as long as you have a laptop, or a pc, you should be fine. 
And if you have a phone, why are you reading this?

There are many distros, ranging from fedora, to distros like Arch, or Gentoo (which unfortunatly you will learn about later.)
